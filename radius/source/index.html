Radius 原始碼與建置說明

適用 Radius 1.0（iPhone）｜更新：2026 年 10 月 16 日

Radius 用到以 LGPL 與 MPL 授權的開放原始碼元件。這一頁提供這些元件在 Radius 1.0 裡實際使用的完整對應原始碼、我們的修改，以及建置用的腳本。

1. 這一頁涵蓋什麼

  • Radius 本身不是開放原始碼軟體；下面的授權只適用於這一頁列出的元件。
  • 這裡的檔案對應 App Store 上的 Radius 1.0。之後的版本若更動這些元件，這一頁會更新，舊版的檔案也會留著。
  • 授權全文在 App 的「⋯」›「關於與第三方授權」，也在 files/licenses/。
  • 所有檔案在 files/，每個檔案的 SHA-256 在 SHA256SUMS；英文說明 README.md、中文說明 README.zh-Hant.md。

5. 怎麼建置

  • 需要：Apple 晶片的 Mac、Xcode 27（iOS 27 SDK），以及 Homebrew 的建置工具（每支腳本開頭有列）。路徑不能有空白。
  • FFmpeg 與 FFTools：解開 radius-fftools-1.0.tar.xz，執行 scripts/build_ffmpeg_ios.sh。它會下載上面的壓縮檔（或使用你放在 $RADIUS_FFMPEG_WORK/downloads 的檔案）、核對 SHA-256、確認 configure 的授權是 LGPL 2.1，編出 8 個動態的 xcframework（arm64 實機與 arm64 模擬器，最低 iOS 18）。逐步說明在壓縮檔裡的 README.md。
  • LibreOffice：取出標籤 libreoffice-26.8.1.1，照 README.zh-Hant.md 放好腳本與修補檔，執行 scripts/build_libreoffice_ios.sh device（要好幾個小時）。

6. 把自己編的 FFmpeg 換進 App

  • App（RadiusPhone.app）裡，FFmpeg 與 FFTools 是 Frameworks 資料夾中 8 個獨立的動態 framework，透過 @rpath 載入：FFTools、libavcodec（含 LAME、Opus、libvpx、libwebp）、libavdevice、libavfilter、libavformat、libavutil、libswresample、libswscale。分享延伸（PlugIns/RadiusShare.appex）用的是同一組。
  • App 本身的程式只呼叫 FFTools.h 的 C 介面（fft_start、fft_cancel、fft_run、fft_list_codecs），不直接呼叫 FFmpeg 的函式。改版只要保持 framework 名稱與安裝名稱、FFTools.h 的介面，以及 FFmpeg 9.0 的函式庫主版本（或以你的 FFmpeg 重編 FFTools），就能替換。
  • 做法：用上面的腳本編好，把 Frameworks/<名稱>.framework/<名稱> 換成你編的版本（xcframework 的 ios-arm64），再依序用你自己的憑證與描述檔重新簽 8 個 framework、分享延伸與 App，用 Xcode 或 xcrun devicectl 裝到你的 iPhone。詳細步驟在 radius-fftools-1.0.tar.xz 的 README.md。

5. How to build

  • You need a Mac with Apple silicon, Xcode 27 (iOS 27 SDK), and the Homebrew build tools listed at the top of each script. Paths must not contain spaces.
  • FFmpeg and FFTools: unpack radius-fftools-1.0.tar.xz and run scripts/build_ffmpeg_ios.sh. It downloads the tarballs above (or uses the ones you put in $RADIUS_FFMPEG_WORK/downloads), checks their SHA-256, confirms that configure reports LGPL 2.1, and builds eight dynamic xcframeworks (arm64 device and arm64 simulator, minimum iOS 18). Step-by-step instructions are in the README.md inside the archive.
  • LibreOffice: check out tag libreoffice-26.8.1.1, place the script and the patch as described in README.md, and run scripts/build_libreoffice_ios.sh device (this takes several hours).

6. Using your own FFmpeg in the app

  • In the app bundle (RadiusPhone.app), FFmpeg and FFTools are eight separate dynamic frameworks in the Frameworks folder, loaded through @rpath: FFTools, libavcodec (with LAME, Opus, libvpx and libwebp), libavdevice, libavfilter, libavformat, libavutil, libswresample and libswscale. The share extension (PlugIns/RadiusShare.appex) uses the same ones.
  • The app's own code calls only the C interface in FFTools.h (fft_start, fft_cancel, fft_run, fft_list_codecs); it does not call FFmpeg functions directly. A modified version can replace them as long as it keeps the framework names and install names, the FFTools.h interface, and the FFmpeg 9.0 library major versions (or you rebuild FFTools against your FFmpeg).
  • How: build with the script above, replace each Frameworks/<name>.framework/<name> with your build (the ios-arm64 slice of the xcframework), re-sign the eight frameworks, the share extension and the app, in that order, with your own certificate and provisioning profile, and install it on your iPhone with Xcode or xcrun devicectl. Detailed steps are in the README.md inside radius-fftools-1.0.tar.xz.
